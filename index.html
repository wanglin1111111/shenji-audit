📖 使用说明书（点开看完整步骤与免费实时体验教程）

一、零配置快速体验（不需要任何账号，1 分钟）

  1. 点击上方任一样例（推荐先点「违规·跨境金融技能片段」）；
  2. 点「▶ 运行规则审计」——毫秒级出发现，每条带行号证据；
  3. 点「▶ 运行语义审计」——内置样例自动载入预生成的语义审计结果（页面会明确标注"离线缓存"）；
  4. 在每条发现的下方点「采信」或「驳回」完成人工复核（这就是合规工作流的"待人工复核→定性→留痕"）；
  5. 点「双样例断言」查看引擎自身的验证结果；点「导出审计底稿」下载 Markdown 底稿。

二、免费实时体验语义引擎（自定义文本也想要 AI 实时审？3 步获取免费 Key）

  1. 打开 open.bigmodel.cn（智谱开放平台）注册账号，新用户一般有免费额度，并提供免费/低成本档模型（以平台当期牌价为准）；
  2. 在控制台进入「API Keys」，创建并复制密钥；
  3. 回到本页，把密钥粘贴到下方输入框（只存你这个浏览器，不经过任何服务器），模型建议先选「glm-4-flash（免费/低成本档）」，点「▶ 运行语义审计」即可实时出结果。

试用满意后再决定是否升级为效果最好的 glm-5.3（换一下模型下拉框即可，Key 不用换）。

三、合规工作流是怎么运转的

  • AI 只产出"待人工复核"的线索（附证据坐标），永远不做定性；
  • 审计员点「采信 / 驳回」完成定性，动作写入「审计轨迹」；
  • 「双样例断言」保证引擎自身被审计：违规样例必须拦截、合规样例必须放行；
  • 「导出审计底稿」输出带审计编号、样本文本指纹、复核记录与结论的 Markdown 底稿。

四、常见问题

  • 文字看不清？请使用 Chrome / Edge 最新版，并在浏览器设置中关闭"强制深色模式"（本页为浅色宣纸风格设计）；
  • 语义审计提示"离线缓存"？表示展示的是预生成结果；填入 Key 后同一样例可实时重审；
  • 数据安全？规则引擎纯本地；语义引擎仅在填 Key 时把待审文本直连智谱 API，不经过任何中间服务器。
