# 审迹 SHENJI · 证据链式 AI 审计员

> 智绘未来 · 业财AI创新黑客松 2026 · AI+审计合规赛道 · 初赛 MVP
> 在线体验：https://wanglin1111111.github.io/shenji-audit/

让每一条审计结论都有证据坐标：对企业 AI 资产（技能 / 知识库 / 合规文档 / 验证报告）做双引擎合规审计，每条发现附 `行号 + 原文` 证据，未经人工复核不定性，全程轨迹留痕，可导出审计底稿。

## 双引擎

| 引擎 | 运行方式 | 职责 |
|---|---|---|
| **规则引擎**（本地，确定性） | 浏览器内运行，无需密钥 | 监管红线模式（分拆购汇/化整为零/规避监管）、frontmatter 触发路由缺失、自证式假验证、结构编号重复、灰色操作表述；含**防护语境豁免**（禁止性表述不误报） |
| **语义引擎**（GLM-5.3） | 浏览器直连智谱 Anthropic 协议 API | 语义级识别"把违规包装成建议"、法规引用错误、越界承诺；密钥仅存 localStorage，不经过任何服务器 |

## 防"自证式假验证"：双样例断言

合规样例必须放行（`exit 0`），违规样例必须拦截（`exit 1`），两者同时成立引擎才可信——没有失败样例的通过不予采信。内置三个真实案例改编样例：

- `bad-1` 跨境金融技能：外管局明令禁止的"大额资金分批出境"被包装成实操建议（源自 2026-08 真实排查发现）
- `bad-2` TEST.md 自证式假验证：通过率 100% 却零断言、零失败样例
- `good-1` 合规技能：应零红线放行

## 人工兜底闭环

每条发现初始状态为「待人工复核」，审计员可「采信 / 驳回」；全部动作写入审计轨迹，一键导出 Markdown 审计底稿（含审计编号、文本指纹、证据坐标、复核记录、审计结论）。

## 本地运行

无构建、无依赖，任意静态服务器即可：

```bash
npx serve .        # 或 python -m http.server
```

可选：重新生成内置样例的离线语义缓存：`node gen-cache.mjs`（需 GLM API Key）。

## 数据与合规

- 规则引擎：纯本地运行，输入不出浏览器；
- 语义引擎：输入直连智谱 API（不经过任何中间服务器），API Key 仅存本浏览器 localStorage；
- 内置样例为真实排查案例的改编节选，不含真实主体信息。
